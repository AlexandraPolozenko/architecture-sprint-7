# Список требований

## Требования к безопасности
- Шифрование данных: Все данные, передаваемые между PropDevelopment и внешними системами, должны быть зашифрованы (HTTPS/TLS).
- Конфиденциальность данных: Обработка и хранение данных (биометрии и номера автомобилей) должны выполняться в соответствии с корпоративным и законодательным стандартам безопасности (152-ФЗ)
- Контроль доступа: Ролевая модель (RBAC)
- Аудит логов и мониторинг: Вести подробные логи всех взаимодействий с платформой партнёра, реагировать на потенциальные нарушения безопасности

## Протоколы аутентификации и авторизации
- OAuth 2.0: Авторизации и аутентификации системами предприятия и внешней платформой

## Взаимодействие систем
Собственник отправляет запросы в мобильное приложение "Витрина сервисов для собственников", которое отправляет их в микросервис tenant-smart-home-app. Тот взаимодействует с внещней платформой "Умный дом" (посылает запросы открыть шлагбаум/домофон).
