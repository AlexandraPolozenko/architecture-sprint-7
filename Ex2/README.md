# architecture-sprint-7

В проверочный лист стоит добавить:

**Управление доступом**
- Многофакторная аутентификация - современная защита доступа к системам
- Принцип минимальных привелегий - сейчас могут поулчить доступы к данным, не требующимся для работы
- Регулярный аудит учетных записей - проверка принципа минимальных привелегий, удаление доступов для увольвшихся сотрудников, пересмотр ролей
- Журналирование операций доступа к системам - возможность быстрее расследовать инциденты ИБ и замечать несанкционированный доступ

**Безопасность данных**
- Политика классификации данных - сейчас данные передаются без каких-либо ограничений (могут передать и персональные данные)
- Шифрование данных - передаются по сети и персональные данные и комерческая тайна

**Защита инфраструктуры**
- Сканирование уязвимостей - процесс отсутствует, позволит раньше выявлять и устранять существующие уязвимости

**Управление инцидентами**
- Система мониторинга событий безопасности - позволит выявлять аномалии и несанкционированный доступ

**Специфические аспекты**
- VPN - для безопасного удаленного доступа к ресурсам
